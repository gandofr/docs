# Contacter le support Gando

Avant d’envoyer une demande, consultez la [**FAQ**](/support/faq) ou les [**problèmes courants**](/support/common-issues) : la réponse y est peut-être déjà disponible.

## Pour obtenir une réponse plus rapidement

Indiquez dans votre demande :

- votre adresse e-mail de connexion ;
- le nom de votre entreprise si vous êtes loueur ;
- la caution ou l’opération concernée ;
- ce que vous essayiez de faire ;
- le message d’erreur affiché ;
- une capture d’écran lorsque cela peut aider à comprendre le problème.

<Warning>
  Ne communiquez jamais votre mot de passe, votre client secret API ou des données bancaires confidentielles dans votre demande.
</Warning>

<Card title="Envoyer une demande d’assistance" icon="paper-plane" href="https://www.gando.app/demande-d-assistance">
  Ouvrez le formulaire d’assistance Gando et décrivez votre problème.
</Card>
