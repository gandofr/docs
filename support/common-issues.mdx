## Avant de contacter le support

Pour nous permettre de vous aider rapidement, préparez si possible :

- l’adresse e-mail utilisée sur votre compte Gando ;
- le nom de votre entreprise si vous êtes loueur ;
- l’identifiant ou le lien de la caution concernée ;
- une capture de l’erreur affichée ;
- l’étape exacte à laquelle le problème se produit.

<Note>
  Ne transmettez jamais votre **client secret API**, votre mot de passe ou des informations bancaires confidentielles dans une demande de support.
</Note>
